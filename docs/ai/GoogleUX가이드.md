# Google UX 가이드라인 (Material Design 기반)

## 개요

Google의 UX 철학은 사용자가 쉽고 빠르게 목표를 달성할 수 있도록 돕는 데 초점을 맞춘다. 특히 Material Design을 통해 일관성 있고 직관적인 사용자 경험을 제공하는 것을 중요하게 생각한다.

---

# 1. 명확성 (Clarity)

사용자는 현재 위치와 가능한 행동을 쉽게 이해할 수 있어야 한다.

## 원칙

* 화면의 목적을 명확하게 전달한다.
* 복잡한 정보를 단순하게 표현한다.
* 중요한 행동은 눈에 띄게 배치한다.
* 이해하기 쉬운 문구를 사용한다.

## 좋은 예시

* "저장", "삭제", "수정" 등 명확한 버튼명 사용
* 현재 진행 상태 표시
* 직관적인 아이콘 활용

---

# 2. 일관성 (Consistency)

동일한 행동은 항상 동일한 방식으로 동작해야 한다.

## 원칙

* 동일한 UI 패턴을 유지한다.
* 버튼 위치와 스타일을 통일한다.
* 용어를 일관되게 사용한다.
* 사용자가 학습한 경험을 재사용할 수 있도록 설계한다.

## 좋은 예시

* 모든 화면에서 동일한 뒤로가기 방식 제공
* 동일한 의미의 버튼은 동일한 색상 사용

---

# 3. 사용자 중심 설계 (User-Centered Design)

시스템이 아닌 사용자의 목표를 중심으로 설계한다.

## 원칙

* 사용자의 주요 작업을 우선시한다.
* 불필요한 입력을 최소화한다.
* 사용자의 인지 부담을 줄인다.
* 실제 사용 환경을 고려한다.

## 좋은 예시

* 자동완성 제공
* 기본값 설정
* 반복 입력 최소화

---

# 4. 피드백 제공 (Feedback)

모든 사용자 행동에는 적절한 피드백이 제공되어야 한다.

## 원칙

* 클릭 결과를 즉시 알려준다.
* 로딩 상태를 표시한다.
* 오류 발생 시 원인과 해결 방법을 안내한다.

## 좋은 예시

* 저장 완료 메시지
* 진행률 표시
* 성공 및 실패 알림

---

# 5. 효율성 (Efficiency)

사용자가 최소한의 노력으로 목표를 달성할 수 있어야 한다.

## 원칙

* 클릭 수를 줄인다.
* 반복 작업을 자동화한다.
* 자주 사용하는 기능을 쉽게 접근할 수 있게 한다.

## 좋은 예시

* 단축키 지원
* 즐겨찾기 기능
* 최근 사용 항목 제공

---

# 6. 접근성 (Accessibility)

모든 사용자가 서비스를 이용할 수 있어야 한다.

## 원칙

* 충분한 색상 대비 제공
* 키보드 조작 지원
* 스크린 리더 지원
* 명확한 라벨 제공

## 좋은 예시

* 버튼에 aria-label 제공
* 적절한 폰트 크기 사용
* 색상만으로 정보를 전달하지 않음

---

# 7. 오류 예방 (Error Prevention)

오류를 수정하는 것보다 예방하는 것이 중요하다.

## 원칙

* 위험한 작업은 확인 절차를 제공한다.
* 입력값을 사전에 검증한다.
* 사용자의 실수를 방지하는 UI를 설계한다.

## 좋은 예시

* 삭제 전 확인 모달
* 실시간 폼 검증
* 되돌리기(Undo) 기능

---

# 8. 시각적 계층 구조 (Visual Hierarchy)

사용자가 중요한 정보를 먼저 볼 수 있도록 설계한다.

## 원칙

* 중요한 정보는 크게 표시한다.
* 관련 요소를 그룹화한다.
* 적절한 여백을 활용한다.

## 좋은 예시

* 제목 > 부제목 > 본문 구조
* 카드 기반 레이아웃
* 충분한 공백 활용

---

# 9. 반응성과 성능 (Performance)

빠른 인터페이스는 좋은 UX의 핵심 요소이다.

## 원칙

* 빠른 응답 속도를 제공한다.
* 사용자가 기다리는 시간을 최소화한다.
* 지연이 발생할 경우 상태를 표시한다.

## 좋은 예시

* Skeleton UI
* Lazy Loading
* Optimistic UI

---

# 10. 자연스러운 인터랙션 (Motion & Interaction)

애니메이션은 기능을 설명하는 수단이어야 한다.

## 원칙

* 움직임에는 목적이 있어야 한다.
* 과도한 애니메이션을 피한다.
* 상태 변화를 자연스럽게 연결한다.

## 좋은 예시

* 화면 전환 애니메이션
* 버튼 클릭 효과
* 모달 등장 애니메이션

---

# 핵심 체크리스트

* 사용자가 무엇을 해야 하는지 즉시 알 수 있는가?
* 중요한 행동이 눈에 잘 띄는가?
* UI가 일관성을 유지하는가?
* 오류 발생 가능성을 줄였는가?
* 모든 사용자에게 접근 가능한가?
* 빠르고 반응성이 좋은가?
* 불필요한 복잡성을 제거했는가?

---

## 결론

Google UX의 핵심은 단순히 예쁜 화면을 만드는 것이 아니라, 사용자가 쉽고 빠르게 목표를 달성할 수 있도록 돕는 것이다. 따라서 명확성, 일관성, 접근성, 효율성, 피드백 제공을 중심으로 설계하는 것이 중요하다.
