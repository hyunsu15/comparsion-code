## 의견 유형(opinion_type) — 스레드 단위 5종 강제 선택 + 배지 + 유형별 필터 (사용자 요청)

- 요청: 스레드를 **처음 열 때(새 의견 작성) 의견 유형을 무조건 선택**하도록 강제. 유형 5종: 불일치 의심(MISMATCH)/누락 의심(OMISSION)/설명 요청(EXPLANATION)/업무 확인 필요(BUSINESS_CHECK)/기타(ETC). create.sql·insert.sql도 함께 반영.
- 결정(사용자 확인): ①유형은 **스레드 단위**(새 스레드 생성 시 1회 필수, 답글엔 없음) ②표시 = 배지 + 의견 모아보기 **유형별 필터** ③기존 데이터는 신경 안 씀(지워도 되는 요소). `reaction`과 동일 패턴(thread 메타데이터의 별도 축)으로 추가하되, reaction은 생성 후 PATCH인 반면 opinion_type은 **생성 시 필수**(status 경로).

## 리액션 권한 — 본인 측 글에는 리액션 불가 (사용자 요청)
