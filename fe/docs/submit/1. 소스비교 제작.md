## 1. 개요

PB(구버전, Pro\*C/C) 시스템을 PB5(신버전, Java/XML)로 전환하는 과정에서, **전환 전·후 소스가 동일한 업무 로직을 수행하는지**를 사람이 눈으로 비교·검증해야 한다. 기존에는 두 소스를 각각 열어 수작업으로 대조했기 때문에 시간이 많이 들고 누락·오판이 발생했다.

본 도구는 **PB 소스와 PB5 소스를 한 화면에서 나란히 비교**하고, **메서드 단위 이동·접기**, **라인별 토론(의견)** 으로 검증 작업을 표준화·효율화하기 위해 제작되었다. 초기 버전(1.0) 이후 검증 결과를 **모아서 관리·보고**할 수 있도록 **의견 모아보기**와 **점검 체크리스트**를 추가하여, 개별 프로그램 검증에서 **전체 이관 물량의 진행 관리**까지 한 도구에서 처리한다.

## 2. 추진 배경

- PB → PB5 마이그레이션 물량이 많아 수작업 대조의 한계가 명확함.
- 검증 결과(확인 요청/이슈)를 소스 라인에 직접 남기고 담당자 간 주고받을 수단이 필요함.
- 분류(대분류)·업무(중분류)·프로그램명 체계로 비교 대상을 빠르게 찾을 수 있어야 함.
- **(2.0 추가)** 프로그램별로 흩어진 의견을 한 곳에 모아 상태·유형별로 조회하고, 조치 여부를 추적해야 함.
- **(2.0 추가)** 프로그램마다 동일 기준(표준 점검 문항)으로 점검했는지 확인할 수단이 필요함.

## 3. 목표 및 기대효과

| 구분 | 내용 |
|---|---|
| 목표 1 | PB(C/Pro\*C)와 PB5(Java/XML) 소스를 좌·우 동시 비교 |
| 목표 2 | 메서드 인식 기반의 빠른 이동·접기·검색으로 대조 시간 단축 |
| 목표 3 | 라인 단위 토론(의견)으로 검증 이슈를 소스에 귀속하여 관리 |
| 목표 4 | 의견을 모아보기로 집계해 **담당자 확인 차례·조치 상태**를 추적 |
| 목표 5 | 표준 점검 문항(체크리스트)으로 프로그램별 검증 진행률 관리 |
| 기대효과 | 검증 시간 단축, 누락 감소, 검증 이력·진행률의 추적성 확보 |

## 4. 적용 범위

- **PB(구버전)**: Pro\*C/C 소스(`.pc`, `.c`, `.h`)
- **PB5(신버전)**: Java 소스(`.java`), MyBatis 매퍼(`.xml`)
- **비교 대상 관리**: 분류(대) → 업무(중) → 프로그램명 3단계 카탈로그
- **검증 협업**: 라인별 스레드/답글, 상태(PB 확인 / PB5 확인 / 해결), 의견 유형 5종, 처리 리액션 3종
- **진행 관리**: 표준 점검 문항 × 프로그램 매트릭스(5단계 상태)
- **제외**: PB/PB5 원천 소스 자체의 수정(도구는 비교·기록·추적까지)

## 5. 화면 구성 (2.0)

| 탭 | 하는 일 |
|---|---|
| **소스 비교** | 좌(PB)·우(PB5) 코드를 나란히 보고, 메서드 접기 / 대응 메서드 점프 / 좌·우 개별 검색 / 동기 스크롤. 코드 줄에 **Shift+클릭**으로 의견을 남긴다. 체크리스트 패널·SQL 대응 패널 포함 |
| **의견 모아보기** | 여러 프로그램의 의견(스레드)을 모아 답글·리액션(조치 구분)·처리 완료를 진행. 상태·의견 유형·업무·즐겨찾기로 필터, 페이지 번호 페이징 |
| **체크리스트 모아보기** | 프로그램 × 점검 문항 매트릭스로 전체 진행률과 미판정 항목을 조망(읽기 전용) |

## 6. 주요 기능 요약

| # | 기능 | 설명 | 도입 |
|---|---|---|---|
| 1 | 비교 대상 선택 | 분류·업무·프로그램명으로 좌(PB)/우(PB5) 소스 자동 로드 | 1.0 |
| 2 | 좌·우 비교 뷰 | 문법 하이라이팅 + 대용량 가상 스크롤 | 1.0 |
| 3 | 메서드 인식 | C/Java 소스에서 메서드(함수) 자동 추출 | 1.0 |
| 4 | 메서드 점프 | 프로그램ID가 `파일.메서드` 형태면 자동 이동, 반대편 대응 메서드 이동(Alt+클릭) | 1.0 |
| 5 | 접기 | 메서드 단위 접기/펼치기, 전체 접기, **import/include 묶음 접기** | 1.0 / 2.0 |
| 6 | 동기 스크롤 | 좌·우 스크롤 연동(가운데 체인 버튼 + 단축키) | 1.0 |
| 7 | 라인 토론 | 라인별 스레드/답글, 상태별 마커 색상, 마커 개수 요약 | 1.0 |
| 8 | 인코딩 자동 복원 | EUC-KR(CP949) PB 소스 한글 깨짐 자동 복원 | 1.0 |
| 9 | 가독성 옵션 | 글자 크기 조절, 좌·우 패널 너비 조절 | 1.0 |
| 10 | **코드 내용 검색** | 좌·우 패널 개별 검색(Ctrl+F), 매치 하이라이트·이동 | 2.0 |
| 11 | **의견 유형** | 스레드 생성 시 5종(불일치 의심/누락 의심/설명 요청/업무 확인 필요/기타) 강제 선택, 배지·필터 | 2.0 |
| 12 | **처리 리액션** | 메시지 단위 3종(확인중/조치 완료/조치 불필요), 스레드 제목에 최근 리액션 표시 | 2.0 |
| 13 | **의견 모아보기** | 분류별·전체 스레드 집계, 상태/유형/업무/즐겨찾기 필터, 페이지 번호 페이징 | 2.0 |
| 14 | **SQL 대응 보기** | PB5 Java의 매퍼 호출 줄 → 대응되는 PB 인라인 `EXEC SQL` ↔ PB5 매퍼 XML 구문 비교 | 2.0 |
| 15 | **체크리스트** | 표준 점검 문항 × 프로그램, 5상태(선택안함/예/아니오/해당없음/판단 보류) + 메모 | 2.0 |
| 16 | **체크리스트 모아보기** | 전 프로그램 매트릭스·진행률·유형/업무 필터, 대용량 가상 스크롤 | 2.0 |
| 17 | **즐겨찾기** | 자주 보는 프로그램 ★ 표시(브라우저 로컬 저장), 선택바·모아보기 연동 | 2.0 |

## 7. 기술 스택

| 구분 | 기술 |
|---|---|
| 프론트엔드 | React 19, Vite 8, TypeScript, Tailwind CSS 4, Shiki(하이라이팅), TanStack Virtual(가상 스크롤) |

## 9. 검증 흐름 (요약)

```
[분류 선택] → [업무 선택] → [프로그램명 선택]   (★ 즐겨찾기 빠른 선택)
        ↓
[좌: PB 소스 로드]   [우: PB5 소스 로드]   (프로그램ID → parser → 실제 파일 매칭)
        ↓
[하이라이팅 · 메서드 인식 · 자동 점프 · 검색 · SQL 대응 보기]
        ↓
[Shift+클릭 → 의견 작성(유형 선택)] → [상대 담당자 답글 · 리액션] → [스레드 종료]
        ↓
[의견 모아보기: 상태·유형별 추적]   [체크리스트: 프로그램별 점검 진행률]
```
